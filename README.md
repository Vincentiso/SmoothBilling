# SmoothBilling
A solo-founder MVP invoicing tool for independent freelancers.

## Tech Stack
- **Front End:** Semantic HTML5, Responsive CSS, Vanilla JavaScript
- **Back End:** Python (Flask)
- **Storage:** JSON files

## Setup & Run
1. Create a virtual environment: `python -m venv venv`
2. Activate it (Windows): `.\venv\Scripts\Activate.ps1`
3. Install dependencies: `pip install -r requirements.txt`
4. Create a `.env` file with `SECRET_KEY=your_secret` and `FLASK_DEBUG=False`
5. Run the app: `python app.py`
